# DB Viewer - Просмотр карточек сотрудников

## Описание
Приложение для просмотра данных сотрудников из SQLite базы данных.
Интегрировано с Telegram-ботом и использует общую БД и папку документов.

## Функции
- Поиск сотрудников по ФИО
- Просмотр всех записей
- Просмотр документов по категории гражданства (Патент, Студент, ЕАЭС, РВП, ВНЖ, Россия)
- Просмотр фото и документов с возможностью открытия
- Экспорт данных в PDF

## Структура проекта
```
urisconsult/
├── bot/
│   ├── Users/
│   │   └── users.db          # Общая БД (бот пишет, UI читает)
│   └── services/
│       └── db.py
├── users/
│   └── docs/                 # Общая папка документов
│       ├── photo_00001.jpg
│       ├── pas_00001.jpg
│       └── ...
└── UI/
    ├── db_viewer.py          # Основное приложение
    ├── build_exe.py          # Скрипт для сборки в exe
    ├── requirements.txt      # Зависимости Python
    └── run.bat               # Скрипт запуска
```

## Хранение данных
- **База данных**: `bot/Users/users.db` (SQLite)
- **Документы**: `users/docs/` (изображения паспортов, патентов и т.д.)

## Именование файлов документов
Файлы документов находятся в `users/docs/` и именуются по шаблону:
`{prefix}_{ID}.{расширение}`

Примеры:
- `photo_00001.jpg` — фото сотрудника
- `pas_00001.jpg` — паспорт
- `pat_00001.jpg` — патент
- `reg_00001.jpg` — регистрация
- `snils_00001.jpg` — СНИЛС
- `inn_00001.jpg` — ИНН

## Установка и запуск

### Для разработки:
1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

2. Запустите приложение:
   ```
   python db_viewer.py
   ```

### Создание exe файла:
1. Запустите скрипт сборки:
   ```
   python build_exe.py
   ```

2. Исполняемый файл будет создан в папке `dist/`

## Использование
1. Запустите приложение (или `run.bat`)
2. Введите ФИО для поиска или нажмите "Показать всех"
3. Выберите запись из списка
4. Просмотрите данные и документы
5. При необходимости нажмите "Экспорт в PDF"

## Требования

- Библиотеки: Pillow, reportlab
- Windows (для exe файла)
