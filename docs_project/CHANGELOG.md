## v3.1 (27.07.2026)

Переход с SQLite-over-SMB на HTTP API. API-сервер запускается вместе с ботом.

### Архитектура — HTTP API
- **`bot/api_server.py`** — Flask-сервер (12 эндпоинтов, порт 8080)
- **`UI/src/api_client.py`** — HTTP-клиент (urllib.request, 0 зависимостей)
- Бот + API запускаются в одном окне (Flask в daemon-потоке)
- UI обращается к `http://IP:8080/api/...` вместо сетевой папки
- Файлы документов отдаются через `/docs/<worker_id>/<filename>`
- Кэширование скачанных файлов в `~/.urisconsult_cache/`

### Убрано
- Сетевой доступ через SMB (`\\144.76.70.246\...`)
- `NETWORK_SERVER` → `API_SERVER` в `.env`
- Проверка доступности сервера с таймаутом (3-10 сек)
- Fallback на локальную БД — теперь唯一 путь через API

### Документы — новые типы для патента
- Перевод паспорта — отдельный пункт (`patent_passport_translation`)
- Патент: 2 фото — лицевая (`patent_patent_front`) + разворот (`patent_patent_back`)
- Дактилоскопия: 2 фото — лицевая (`patent_fingerprint_front`) + разворот (`patent_fingerprint_back`)
- Чеки по патенту: до 3 штук (`patent_receipt_1/2/3`)
- СНИЛС — отдельный от перевода паспорта

### UI — исправления
- Убран `email` из полей карточки
- Гражданство отображается в карточке (было только в данных)
- Документы загружаются через HTTP вместо прямого доступа к файлам
- Логи с датой и временем (было только время)

### БД — улучшения сети
- `busy_timeout`: 5с → 30с (бот и UI)
- `PRAGMA synchronous=NORMAL`, `locking_mode=NORMAL`
- Ретраи при `database is locked`: 5 → 20 с экспоненциальной задержкой
- `_sync_docs_from_disk()` — коммит после каждого работника
- `get_next_id()` — убран `BEGIN IMMEDIATE`

### Зависимости
- Добавлен `flask>=3.0.0` (сервер)
- Клиент: 0 новых пакетов (urllib.request — stdlib)

## v3.0 (21.07.2026)

Аудит кодовой базы: исправление критических багов, устранение дублирования, общая схема БД.

### Критические исправления
- **Race condition в `get_next_id()`** — `BEGIN IMMEDIATE` + временная запись для атомарного получения ID
- **`INSERT OR REPLACE` → `ON CONFLICT DO UPDATE`** — статус/замечания больше не сбрасываются при повторном сохранении
- **`delete_worker()` в UI** — удаление по папке `docs/{id}` вместо неверного glob-паттерна
- **Дубли встреч в `save_worker()`** — `DELETE` перед `INSERT` предотвращает дублирование

### Совместимость бот + UI
- **`PRAGMA journal_mode=WAL`** добавлен в UI (был только в боте) — читатели не блокируют писателей
- **`PRAGMA busy_timeout=10000`** — увеличен в обоих компонентах (было 5000ms)
- **Таймаут подключения UI** — уменьшен с 60 до 15 сек
- **Защита `_do_init_db()`** — синхронизация файлов не падает если БД заблокирована ботом

### Splash screen
- Splash остаётся видимым пока приложение загружается (был скрыт до завершения)
- Передаётся в `main()` и закрывается после инициализации `DBViewerApp`

### NETWORK_SERVER в конфигурации
- IP-адрес сервера перенесён из хардкода в `.env` файл (`NETWORK_SERVER=...`)
- Бот: читается через `os.getenv("NETWORK_SERVER")`
- UI: читается напрямую из `.env` (до инициализации `get_paths()`)

### Общая схема БД
- Создан модуль `shared/__init__.py` — единый источник истины для таблиц
- UI импортирует схему из `shared/` вместо дублирования

### Устранение дублирования
- Удалён `_DOC_LABELS_FALLBACK` (~50 строк) из `main.py`
- Удалён `_DOC_FALLBACK` (~40 строк) из `dialogs.py`
- Удалён мёртвый `__getattr__` из `registration.py`
- Дубли `_log()` → единая `diagnostic_log()` в `logging_config.py`
- Удалён дубль `MockDocumentType` в `test_services.py`

### Безопасность и качество
- Whitelist-валидация полей поиска в `WorkerRepository.search()`
- `format_phone()` поддерживает международные номера
- Pillow версия унифицирована `>=10.0.0`
