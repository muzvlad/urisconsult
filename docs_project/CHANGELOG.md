## v2.2 (13.07.2026)

Система обработки анкет: колокольчик уведомлений, принятие/отклонение, возврат на доработку.

### UI
- Колокольчик уведомлений — иконка + серый кружок с количеством pending анкет
- Панель обработки — окно со списком новых анкет (клик по колокольчику)
- Принятие анкеты — кнопка "Принять" ставит статус `accepted`
- Отклонение анкеты — выбор полей для исправления через чекбоксы
- Отправка замечаний клиенту в Telegram
- Статус в списке — ⏳/✅/❌ рядом с каждой анкетой
- Панель замечаний в карточке (жёлтая секция)
- Центрирование всех окон по центру экрана
- Кнопки в окне отклонения: "Отмена" + "Отклонить и отправить"
- Scrollbar в окне отклонения

### Бот
- `/start` проверяет `telegram_id` → ищет отклонённую анкету
- Если отклонена: предлагает "Исправить" или "Новая анкета"
- Исправление: запрашивает только отклонённые поля
- При переподаче: статус → `pending` (снова в колокольчике)

### БД
- Новые колонки: `status`, `rejection_reasons`
- Новые функции: `get_pending_workers()`, `accept_worker()`, `reject_worker()`, `resubmit_worker()`
- Исправление России: убран дубль `russia_propiska`

### Тесты
- 5 тестовых анкет (Тестовый*) с разными статусами
- Скрипт `seed_test_data.py`

## v2.1 (11.07.2026)

Рефакторинг архитектуры: нормализованная БД, единый конфиг документов, generic handlers, тесты.

### Бот
- **config/documents.py** — единый источник истины для типов документов
  - `DocumentType` dataclass (key, label, prefix, required, can_skip, category)
  - `DOC_FLOWS` — порядок документов по 6 категориям
  - Автогенерация: `DOC_PREFIXES`, `DOC_LABELS`, `DOC_PROMPTS`, `CITIZENSHIP_DOC_KEYS`
  - Хелперы: `get_doc_flow()`, `get_next_doc()`, `get_doc_by_key()`
- **Нормализованная БД** (3NF):
  - `workers` — личная информация (18 колонок вместо 100+)
  - `worker_documents` — документы (worker_id, doc_type, filename)
  - `worker_meetings` — встречи (worker_id, date, note)
  - Индексы по worker_id, doc_type, name
- **Автоматическая миграция** со старой схемы (100+ колонок) → новая (3 таблицы)
- **Generic document handler** — 1 вместо 60+ функций-обработчиков
- **Динамический FSM** — WorkerForm генерируется из конфига
- **Rate limiting** — ThrottlingMiddleware (5 сообщений / 10 сек)
- **Логирование** — RotatingFileHandler, структурированные логи
- **Бэкапы** — скрипт `backup_db.py` (автоочистка старых)
- **Валидация файлов** — проверка MIME-типа и размера (20MB max)

### UI
- Импорт общего конфига документов из `bot/config/documents.py`
- Работа с нормализованной БД (SELECT из 3 таблиц)
- Убрано дублирование `CITIZENSHIP_DOCS`

### Тесты
- 62 теста в `docs_project/tests/`
  - `test_config_documents.py` — конфиг документов, flows, prefixes, labels, prompts
  - `test_db.py` — CRUD, схема, миграция, синглтон
  - `test_handlers.py` — валидация телефона/email/даты, FSM состояния

## v2.0 (10.07.2026)

Объединение бота и UI в единый проект. Переход с JSON на SQLite.

### Бот
- Переход хранения данных с JSON на SQLite (aiosqlite)
- Миграция существующих JSON-файлов в БД
- 40+ типов документов по 6 категориям гражданства
- Общая БД `bot/Users/users.db` для бота и UI

### UI (Десктопное приложение)
- Полная замена JSON-чтения на SQLite
- Динамическое отображение документов по категории гражданства
- Убран выбор папки — фиксированные пути к БД и документам
- Автоматическое создание БД и папок при первом запуске
- Экспорт PDF со всеми документами

### Структура
- Перенос .git из `bot/` в корень проекта
- Единая папка документов `users/docs/`
- Единая документация в `docs/`
- Обновлён .gitignore

## v1.0 (09.07.2026)

Telegram-бот для сбора данных работников.

### Возможности
- Пошаговая анкета через FSM: ФИО, гражданство, пол, должность, объект, адрес, менеджер
- Валидация телефона, email, даты рождения
- Загрузка документов: фото, паспорт, патент, регистрация
- Экран подтверждения с возможностью редактирования любого поля
- Сохранение в JSON + файлы документов
- Кнопка «Начать регистрацию» всегда видна
- Ответ на любое сообщение вне анкеты с предложением нажать старт

### Исправления
- Токен вынесен в .env
- Убран жесткий формат телефона
- Исправлен пропуск документов (ошибка в лямбдах)
- Кнопки клавиатуры не исчезают после нажатия
- Убран дублирующий код в обработчике документов
- Очистка служебных ключей из сохраняемого JSON
- Логирование: только ошибки бота, без шума от библиотек
