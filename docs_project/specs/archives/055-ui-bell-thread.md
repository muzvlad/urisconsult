# Спецификация 012 — UI колокольчик не порождать новый поток каждые 15 с

## Проблема
`UI/src/main.py:_auto_refresh_bell` запускает `threading.Thread` каждые 15 с для запроса `get_pending_count`. Потоки накапливаются (хотя и daemon), нагрузка на API лишняя.

## Что изменить
Использовать `root.after(15000, ...)` в главном потоке или один рабочий поток с `time.sleep`, а не новый поток на каждый тик.

## Критерий приемки
В любой момент времени не более одного активного потока/таймера обновления колокольчика.

## ponytail
Заменить на `root.after` в главном потоке Tkinter.
