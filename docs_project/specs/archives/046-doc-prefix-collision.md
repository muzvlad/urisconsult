# Спецификация 003 — коллизия префиксов документов при синхронизации с диска

## Проблема
Разные категории используют одинаковые префиксы (`snils`, `reg`, `reg_back`, `bank`, `dms`, `inn`, `dactyl_back`, `mig`, `pas_trans`). `bot/services/db.py:526` `_sync_docs_from_disk` строит `prefix_to_doc[doc.prefix] = doc.key` — побеждает последняя по итерации категория. Файл `snils_00001.jpg` работника из категории «Студент» может быть записан в БД как тип документа категории «Патент».

## Что изменить
Не полагаться только на префикс имени файла. При синхронизации сопоставлять файл с документом через существующую запись в `worker_documents` или через составное соотнесение (worker_id + известный набор типов категории работника).

## Критерий приемки
После `_sync_docs_from_disk` каждый файл в папке работника записан под верным `doc_type` категории этого работника.

## ponytail
Не переделывать схему именования файлов; исправить только логику сопоставления при чтении с диска.
