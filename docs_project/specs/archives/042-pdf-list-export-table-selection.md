# Спека 042. Экспорт списка в PDF: таблица 앨범 + выбор анкет для карточек

## Проблема

1. Кнопка «PDF» экспортирует только одну текущую карточку. Нужно уметь выделять
   несколько анкет в списке и экспортировать выбранные в один PDF (каждая
   анкета — на отдельной странице, как карточка).
2. Кнопка «Экспорт списка в PDF» сейчас выгружает внутренности анкет (поля
   карточки по одной на странице). Нужно: альбомная ориентация и именно
   **список** — таблица со столбцами, которые видны в найденных анкетах
   (ID, ФИО, Гражданство, Статус, HR-статус, Телефон, Объект, Заказчик и т.д.).

## Решение

### 1. Выделение анкет в списке (UI/src/widgets.py)

- В `WorkerListWidget` добавить первую колонку `select` с чекбоксом `☐/☑`.
- Клик по чекбоксу переключает выделение анкеты.
- Метод `get_selected_workers() -> list[Worker]` возвращает отмеченные.
- Дополнительно: если ничего не выделено, считать, что выбраны все
  отфильтрованные (видимые) анкеты.

### 2. Кнопка «PDF» — карточки выбранных (UI/src/main.py, UI/src/services.py)

- При нажатии берет выделенные анкеты из списка (или все отфильтрованные,
  если ничего не выделено).
- Экспортирует каждую анкету на отдельной странице PDF (карточка с полями,
  фото сотрудника — как сейчас в `PDFExportService.export`).
- Диалог подтверждения с периодом (как сейчас у экспорта списка).
- Диалог сохранения `.pdf`.

### 3. Кнопка «Экспорт списка в PDF» — таблица альбом (UI/src/main.py, UI/src/services.py)

- Ориентация страницы: альбомная (`landscape`).
- Выгружается таблица: столбцы = те, что видны в списке (ID, ФИО,
  Гражданство, Пол, Дата рождения, Объект, Заказчик, Должность, Телефон,
  Статус анкеты, HR-статус, Дата HR-статуса).
- Каждая анкета — одна строка таблицы.
- Диалог подтверждения с периодом + диалог сохранения.

### Файлы

- `UI/src/widgets.py` — чекбокс колонка в `WorkerListWidget`, `get_selected_workers`.
- `UI/src/services.py` — `PDFExportService.export_list` → альбомная таблица;
  `export` остаётся карточкой (одна анкета на страницу).
- `UI/src/main.py` — кнопка «PDF» экспортирует выбранные карточки; кнопка
  «Экспорт списка в PDF» — альбомная таблица; диалоги периода и сохранения.
- `UI/tests/test_services.py` — тесты на альбомную таблицу и на карточки
  выбранных.

## Критерии приёмки

- [ ] В списке есть колонка с чекбоксами для выделения анкет.
- [ ] Кнопка «PDF» экспортирует выбранные анкеты (или все видимые, если не
      выбрано) — каждая на отдельной странице карточкой.
- [ ] Кнопка «Экспорт списка в PDF» — альбомная ориентация, таблица со
      столбцами, каждая анкета — строка.
- [ ] Диалог подтверждения с периодом перед обеими выгрузками.
- [ ] Тесты проходят.
