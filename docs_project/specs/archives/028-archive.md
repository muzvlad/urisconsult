# Спека 028 — Архив анкет

## Проблема

Завершённые и неактуальные анкеты остаются в общем списке и мешают работе.
Автоматического архива нет и не требуется.

## Решение

Мягкий архив через `workers.archived_at` (миграция v6, спека 021). Физического
удаления нет.

### БД и API

`bot/services/db.py`:

- `archive_worker(worker_id)` — `archived_at = now`, `updated_at = now`;
- `unarchive_worker(worker_id)` — `archived_at = NULL`, `updated_at = now`;
- `get_workers()` и `get_worker()` по умолчанию не фильтруют архив (UI решает сам),
  но новый `get_workers(archived=0|1|all, ...)` поддерживает режим:
  - `0` — только активные (по умолчанию);
  - `1` — только архивные;
  - `all` — все.
- `get_pending_count()` исключает архивные.
- `get_unnotified_meetings()` / выборка напоминаний исключают архивные.
- `resubmit_worker()` очищает `archived_at`, чтобы повторная анкета вернулась в работу.
- `delete_worker()` удаляет связанные `worker_meetings` и `worker_notes`.

`bot/api_server.py`:

- `POST /api/workers/<worker_id>/archive`;
- `POST /api/workers/<worker_id>/unarchive`;
- `GET /api/workers` принимает `archived=0|1|all` (по умолчанию `0`).

`UI/src/api_client.py`: `archive_worker`, `unarchive_worker`,
`get_workers(..., archived=0)`.

### UI

- В карточке кнопка «В архив» с подтверждением.
- Для архивной анкеты — заметная плашка «Анкета в архиве» и кнопка
  «Вернуть из архива».
- В панели над списком `ttk.Combobox` «Показать»: «Активные» (по умолчанию),
  «Архив», «Все».
- Архивная строка в списке отображается серым текстом (тег `archived`),
  HR-цвет фона при этом сохраняется.
- Архивные анкеты остаются доступны для просмотра, PDF и комментариев.
- Добавление встреч и комментариев для архивных не блокируется, но уведомления
  о встречах не отправляются.

Автоматического архивирования нет: только ручное действие пользователя.

## Критерии приёмки

1. Анкета архивируется и исчезает из режима «Активные».
2. В режиме «Архив» видны только архивные анкеты.
3. Анкету можно вернуть из архива.
4. Архивные не попадают в счётчик ожидающих и в уведомления о встречах.
5. Повторная отправка анкеты из бота убирает её из архива.
6. После перезапуска UI архив сохраняется.

- `docs_project/tests/test_archive.py`:

  - фильтры `archived=0/1/all`;
  - исключение из `get_pending_count()`;
  - исключение из выборки уведомлений;
  - `resubmit_worker()` очищает `archived_at`.
- `UI/tests/test_models.py`: `archived_at` в `Worker.to_dict()`.

## Риски

- `worker_notes` появится только после миграции v6, поэтому `delete_worker()` должен
  проверять её наличие или выполняться после `init_db()`.
- Старые анкеты после миграции остаются активными (`archived_at IS NULL`).
