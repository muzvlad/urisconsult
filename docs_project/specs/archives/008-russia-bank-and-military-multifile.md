# Спека 008 — Категория «Россия»: банковские реквизиты + multi-file военный билет

## Проблема

В категории «Россия» (`DOC_FLOWS['Россия']`):
1. Нет документа «Реквизиты банковской карты» — во всех остальных категориях он есть.
2. «Военный билет/Приписное» принимает только один файл, но по бизнес-процессу нужны фото
   **всех страниц с записями** — необходимо несколько файлов.

## Решение

### 1. Новый документ «Реквизиты банковской карты»

- `_RUSSIA_BANK_DETAILS = DocumentType(key='russia_bank_details', label='Реквизиты банковской карты', prefix='bank')`
- Позиция в `DOC_FLOWS['Россия']`: последним (после `_RUSSIA_MILITARY_DOC`), как в остальных категориях.
- Промпт: `'russia_bank_details': '💳 Отправьте реквизиты счета банковской карты:'`

### 2. Военный билет → multi_file

- `_RUSSIA_MILITARY_DOC` получает `multi_file=True`.
- Label уточняется: «Военный билет/Приписное (все страницы с записями)».
- Промпт: `'russia_military_doc': '🎖 Добавьте военный билет или приписное (фото всех страниц, где есть какие-либо записи):'`

Multi-file логика уже реализована в боте (спека 004): копит файлы, «Пропустить» завершает сбор.

### 3. UI

UI читает конфиг из `bot/config/documents.py` — порядок, label и флаг multi_file подхватываются
автоматически. При сборке EXE — пересобрать (bundled копия конфига).

### 4. Тесты

- `docs_project/tests/test_config_documents.py`: «Россия» 6 → 7 документов; добавить тест порядка,
  `russia_bank_details` последним; `russia_military_doc.multi_file is True`.

## Критерии приёмки

1. В категории «Россия» последним документом запрашиваются банковские реквизиты.
2. «Военный билет/Приписное» принимает несколько файлов (фото всех страниц), завершение через
   «Пропустить».
3. Порядок и labels совпадают в боте и UI.
4. Тесты зелёные: `pytest docs_project/tests/ UI/tests/`.

## Файлы

- `bot/config/documents.py` — новый документ, порядок, multi_file, label, промпт.
- `docs_project/tests/test_config_documents.py` — тесты.
- `docs_project/CHANGELOG.md` — запись.
