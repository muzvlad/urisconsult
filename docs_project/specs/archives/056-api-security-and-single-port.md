# Спецификация 056 — безопасность API и единый порт

## Проблема
API (`bot/api_server.py`) слушает `0.0.0.0` без авторизации. `worker_id` из URL подставляется в путь файловой системы: `DELETE /api/workers/..` удаляет каталог `bot/Users` целиком вместе с `users.db`, а `GET /docs/<worker_id>/<file>` отдаёт файлы вне папки документов. Нет лимита размера запроса (20 МБ проверяется только если размер передан явно — в API он не передаётся, проверка не работает), тип файла определяется только по расширению. Порт задан в трёх местах: `bot/bot.py:89` (56755), `bot/api_server.py:425` (8080 — мёртвый код) и `setup.bat:119,132` (подсказка 8080) — setup пишет нерабочий `API_SERVER` в `bot/.env`. Недоступный `NETWORK_SERVER` откатывается на локальную БД молча.

## Что изменить
- `worker_id` и `filename` проверяются регулярным выражением `^[A-Za-z0-9_-]{1,64}$` до любых операций с ФС (один `before_request` на все маршруты).
- `app.config['MAX_CONTENT_LENGTH']` = 20 МБ + 1 МБ на multipart-обвязку; размер файла сверяется с `MAX_FILE_SIZE` при загрузке.
- Тип файла сверяется по magic-байтам (`FileSaver.check_magic`), а не только по расширению.
- Опциональная авторизация: `API_TOKEN` в env → заголовок `X-API-Token`; если токен не задан — API работает как раньше, но бот пишет предупреждение в консоль.
- Порт API — одна константа `API_PORT` в `bot/config/__init__.py` (по умолчанию 56755); `bot/bot.py` и `api_server.py` импортируют её.
- `setup.bat`: подсказка порта 56755; `git checkout -- .` убран, `reset --hard` выполняется только при чистом рабочем дереве.
- UI: `API_TOKEN` читается так же, как `API_SERVER`, и передаётся в заголовке `X-API-Token`.
- Недоступный `NETWORK_SERVER` — предупреждение в лог вместо молчаливого отката.

## Критерий приемки
`DELETE /api/workers/..` возвращает 400 и ничего не удаляет; запрос больше 20 МБ отклоняется; файл с подменённым расширением отклоняется; `setup.bat` предлагает порт 56755 и не затирает локальные правки; при недоступном сетевом диске в лог попадает предупреждение; UI при заданном `API_TOKEN` получает 401 без заголовка и работает с заголовком.

## ponytail
Регулярное выражение вместо новой библиотеки; magic-байты читаются вручную (8 байт); `hmac.compare_digest` из stdlib; порт — одна константа в `config`.
