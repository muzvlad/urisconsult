# Спека 026 — Цветные плашки статусов

## Проблема

Статусы в списке и карточке отображаются обычным текстом, из-за чего смена
HR-статуса не бросается в глаза.

## Решение

Единая палитра статусов в `UI/src/config.py`:

```python
HR_STATUS_STYLES = {
    'not_processed': {'bg': '#E5E7EB', 'fg': '#374151'},
    'docs_pending':  {'bg': '#FEF3C7', 'fg': '#92400E'},
    'employed':      {'bg': '#D1FAE5', 'fg': '#065F46'},
    'rejected':      {'bg': '#FEE2E2', 'fg': '#991B1B'},
    'fired':         {'bg': '#E5E7EB', 'fg': '#6B7280'},
}
```

Неизвестный или пустой статус использует стиль `not_processed`.

### Карточка

- В блоке «HR-статус» рядом с Combobox — `tk.Label` с текстом статуса,
  `bg`/`fg` из палитры, `padx=8`, `pady=2`.
- Плашка обновляется сразу после сохранения статуса.

### Список

- `UI/src/widgets.py`: `Treeview.tag_configure(status, background=...)` для каждого
  HR-статуса.
- При вставке строки назначается тег `hr_<status>`.
- Цвет текста не меняется, чтобы не ломать читаемость выделенной строки.
- В карточке цветная плашка является основным индикатором.

Ограничение Tk: в `ttk.Treeview` нельзя покрасить отдельную ячейку. Поэтому
подсвечивается вся строка лёгким фоном, а насыщенная плашка показывается в карточке.

## Критерии приёмки

1. В карточке HR-статус shown цветной плашкой.
2. В списке строки с разными HR-статусами имеют разный лёгкий фон.
3. Неизвестный статус не ломает отрисовку.
4. Выделение строки остаётся читаемым.

## Тесты

- `UI/tests/test_config.py`: для всех `HR_STATUS_KEYS` есть стиль; неизвестный ключ
  возвращает стиль по умолчанию.

## Риски

- Слишком насыщенный фон мешает читать данные, поэтому в списке используются только
  светлые оттенки, а насыщенные — в плашке карточки.
