# Спека 027 — Формат дат и фильтр по периоду

## Проблема

1. Даты отображаются в ISO (`2026-10-26`, `2026-10-26 14:30:00`), а не в привычном
   `дд.мм.гггг`.
2. В списке нельзя отфильтровать анкеты по периоду.

## Решение

### Форматирование

`UI/src/config.py`:

- `format_date(value) -> str`:
  - `YYYY-MM-DD` -> `дд.мм.гггг`;
  - `YYYY-MM-DD HH:MM:SS` / `YYYY-MM-DDTHH:MM:SS` -> `дд.мм.гггг`;
  - уже `дд.мм.гггг` или `дд.мм.гггг чч:мм` возвращается без изменений;
  - пустое значение -> пустая строка;
  - нераспознанное -> исходная строка.
- `format_datetime(value) -> str` — то же, но с `чч:мм`. Если времени нет,
  возвращает только дату.
- `parse_user_date(text) -> str | None` — принимает `дд.мм.гггг`, возвращает
  `YYYY-MM-DD`; неверная дата -> `None`.

Применение:

- `UI/src/widgets.py`: даты в списке.
- `UI/src/main.py`: карточка, встречи, комментарии, HR-дата.
- `UI/src/services.py`: PDF-профиль и документы.
- `UI/src/dialogs.py`: подписи дат в диалогах.

В БД по-прежнему хранится ISO или существующий формат — меняется только отображение.

### Фильтр по периоду

`UI/src/config.py`: `period_range(preset, today=None) -> tuple[str | None, str | None]`
возвращает ISO-границы включительно:

- `all` -> `(None, None)`;
- `today` -> сегодня/сегодня;
- `week` -> последние 7 дней включая сегодня;
- `month` -> с 1-го числа текущего месяца по сегодня;
- `prev_month` -> весь прошлый месяц;
- `year` -> с 1 января текущего года по сегодня;
- `custom` -> `(None, None)`, границы берутся из полей.

Фильтрация по `workers.created_at` (дата создания анкеты).

`bot/api_server.py`, `GET /api/workers`:

- параметры `date_from`, `date_to` в ISO `YYYY-MM-DD`;
- условие `date(created_at) >= ?` и `date(created_at) <= ?`, обе границы включительно;
- без параметров поведение не меняется;
- неверный формат — 400.

`UI/src/api_client.py`: `get_workers(date_from=None, date_to=None, archived=0)`.

### UI

- Над списком: `ttk.Combobox` «Период»:
  «Все время», «Сегодня», «За неделю», «За месяц», «Прошлый месяц», «За год»,
  «Произвольный».
- При выборе готового периода границы вычисляются и запрос отправляется сразу.
- «Произвольный» включает два поля `с` и `по` (`дд.мм.гггг`) и кнопку «Применить».
- Неверная дата — `messagebox`, запрос не отправляется.
- Фильтр по поиску применяется поверх периода.
- Выбранный период сохраняется в рамках сессии UI, но не в БД.

## Критерии приёмки

1. Все видимые пользователю даты имеют формат `дд.мм.гггг` (при необходимости с временем).
2. PDF показывает даты в том же формате.
3. «За неделю» возвращает анкеты за последние 7 дней включая сегодня.
4. «За месяц» — с 1-го числа текущего месяца.
5. Произвольный период включает обе границы.
6. Неверная дата в произвольном периоде не применяется.
7. Без фильтра список не меняется.

## Тесты

- `UI/tests/test_config.py`:
  - `format_date` для ISO, ISO с временем, уже `дд.мм.гггг`, пустого и мусора;
  - `format_datetime`;
  - `parse_user_date` для валидной и невалидной даты;
  - `period_range` для всех пресетов на фиксированной дате.
- `docs_project/tests/test_api.py`: фильтр `date_from`/`date_to` включительно,
  400 на неверный формат.

## Риски

- `created_at` может быть пустым у старых записей — такие анкеты не попадут в
  период. Это ожидаемо.
- Часовой пояс не учитывается: фильтр работает по дате из БД как есть.
