# Спека 041. Экспорт списка анкет в PDF + убрать фото из PDF-карточки

## Цель

1. В PDF-карточке сотрудника убрать **все фото** (крупное фото сотрудника и
   миниатюры документов) — в PDF не должно попадать ни одного изображения.
2. Добавить кнопку экспорта **текущего отфильтрованного списка анкет** в PDF
   (.pdf) через диалог «Сохранить как». Перед выгрузкой показать предупреждение
   с текстом текущего периода (например, «за все время», «за неделю»,
   «за 01.10.2026 — 28.10.2026») и вопрос «Вы хотите сделать выгрузку?».
   При подтверждении — сохранить файл.

## Проблема

- Сейчас `PDFExportService.export` рисует в PDF фото сотрудника (правый верхний
  угол) и миниатюры документов — пользователь не хочет видеть фото в PDF.
- Есть только PDF по одной анкете. Нет возможности выгрузить список найденных
  анкет в PDF. Excel не использовать (нет зависимости, не хотим nuevas
  зависимости).

## Решение

### 1. PDF без фото

В `UI/src/services.py:PDFExportService.export`:
- убрать рисование фото сотрудника (блок с `ImageReader` / `drawImage` рядом с
  `find_photo`);
- убрать рисование миниатюр документов (блок `c.drawImage(img, 450, ...)`);
- всё остальное (поля анкеты, документы как текст, замечания, встречи) оставить
  без изменений.

### 2. Экспорт списка в PDF

- В `UI/src/services.py` добавить `PDFExportService.export_list(workers,
  output_path)` — многостраничный PDF: заголовок с периодом, затем по одной
  анкете на страницу (или компактно в таблицу) с полями: ID, ФИО, Гражданство,
  Дата рождения, Статус, Дата изменения, Телефон, Объект, Заказчик, HR-статус,
  Дата HR-статуса.
- В `UI/src/main.py`:
  - добавить кнопку «Экспорт списка в PDF» рядом с кнопкой «PDF» на верхней
    панели;
  - при нажатии определить текущий период (`self.period_preset` /
    `self.custom_range`, метки из `self.period_labels`) и составить
    человекочитаемую строку периода («За все время», «За неделю»,
    «За 01.10.2026 — 28.10.2026»);
  - показать диалог: «Будет произведена выгрузка за <период>. Вы хотите
    сделать выгрузку?». При отмене — ничего не делать; при подтверждении —
    открыть диалог `asksaveasfilename` (.pdf) и вызвать
    `PDFExportService.export_list(self.search_results, path)`.
  - если список пуст — показать предупреждение «Нет данных для выгрузки».

## Файлы

- `UI/src/services.py` — убрать фото из `PDFExportService.export`, добавить
  `export_list`.
- `UI/src/main.py` — кнопка «Экспорт списка в PDF», диалог подтверждения с
  периодом, вызов экспорта.
- `UI/tests/test_services.py` — тест на отсутствие фото в PDF и на экспорт
  списка в PDF.

## Критерии приёмки

- [ ] В PDF-карточке не рисуется фото сотрудника и миниатюры документов.
- [ ] Кнопка «Экспорт списка в PDF» есть на верхней панели рядом с «PDF».
- [ ] При нажатии показывается диалог с текущим периодом и вопросом о выгрузке.
- [ ] При подтверждении открывается диалог сохранения .pdf.
- [ ] Выгружаются все анкеты из текущего отфильтрованного списка.
- [ ] Тесты проходят.

## Риски

- Пустой список при выгрузке — показывать предупреждение «Нет данных для
  выгрузки».
- Многостраничный PDF — корректно делать разрыв страниц.
