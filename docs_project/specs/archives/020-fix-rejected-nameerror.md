# Спека 020 — Кнопка «Исправить анкету» молчит (NameError parse_rejection_reasons)

## Проблема

После отклонения анкеты в UI (с комментариями) работник нажимает в Telegram кнопку
«Исправить анкету» — ничего не происходит.

`handle_rejected_callback` (`bot/handlers/commands.py:48`) вызывает
`parse_rejection_reasons(...)`, но функция **не импортирована** в модуль. Обработчик падает
с `NameError`, aiogram молча логирует исключение — пользователь ничего не видит.

Тот же NameError был в `cmd_start` (строка 107) и `any_document` (строка 202) для отклонённых
анкет. Баг предшествует аудиту (в `HEAD~1` импорт тоже отсутствовал) — не был замечен, т.к.
тесты проверяли `_ask_rejected_field` напрямую, а не `handle_rejected_callback`.

## Решение

1. `bot/handlers/commands.py` — добавить `parse_rejection_reasons` в импорт из `utils`.
2. `docs_project/tests/test_commands_fix_rejection.py` — регресс-тесты:
   - кнопка «Исправить анкету» с причиной-документом ставит FSM-состояние документа,
     без исключений;
   - пустые причины — переход к вводу ФИО.

## Критерии приёмки

1. Нажатие «Исправить анкету» показывает «Начинаем исправление анкеты…» и запрашивает
   исправление первого отклонённого поля.
2. Новые тесты зелёные; весь прогон `pytest docs_project/tests/ UI/tests/` зелёный.
