# Спека 011 — Единая палитра кнопок UI в тон интерфейса

## Проблема

Кнопки UI используют «сырые» яркие цвета: голубой `#3498db`, оранжевый `#e67e22`/`#f39c12`,
которые не сочетаются с тёмно-синим header (`#2c3e50`) и серым фоном интерфейса. Кнопки
выглядят пёстро, нет единой стилистики.

Текущие цвета кнопок:
- голубой `#3498db` — «Все анкеты», «Найти», «Просмотр», «Редактировать», «Скачать», «+ Добавить встречу» (main.py, widgets.py)
- оранжевый `#e67e22` — «PDF» (main.py:148)
- оранжевый `#f39c12` — «Заменить» (widgets.py:344)
- красный `#e74c3c` — «Удалить», «Отклонить», «Закрыть»
- зелёный `#27ae60` — «Принять», «Сохранить», «OK»
- серый `#95a5a6` — «Отмена»

## Решение

Задать единую приглушённую палитру в тон тёмно-синему header. Семантические цвета
(зелёный=успех, красный=удаление) сохранить, но приглушить; голубой и оранжевый заменить
на нейтрально-синюю гамму header.

### Палитра (config.py `AppConfig`)

| Ключ | Было | Стало | Использование |
|---|---|---|---|
| `accent_blue` | `#3498db` | `#34495e` | основные действия (тон header, приглушённый тёмно-синий) |
| `accent_orange` | `#e67e22` | `#7f8c8d` | вторичные действия (PDF), приглушённый серо-синий |
| `accent_red` | `#e74c3c` | `#c0392b` | удаление/отклонение (приглушённый красный) |
| `accent_green` | `#27ae60` | `#27ae60` | успех/принять (оставить) |
| `accent_gray` | `#95a5a6` | `#95a5a6` | отмена (оставить) |

Статусные цвета (`status_colors`) не трогаем — они семантические и на кнопках не используются.

### Файлы

1. `UI/src/config.py` — обновить `accent_blue`, `accent_orange`, `accent_red`.
2. `UI/src/widgets.py` — заменить хардкод `#f39c12` → `config.accent_blue`, `#3498db` →
   `config.accent_blue`.
3. `UI/src/main.py:606` — хардкод `#3498db` → `config.accent_blue`.
4. `UI/src/dialogs.py` — хардкод `#e74c3c` → `config.accent_red`, `#95a5a6` → `config.accent_gray`
   (или оставить, если совпадает). Привести к config-константам для единообразия.

## Критерии приёмки

1. Все кнопки UI используют единую приглушённую палитру в тон header.
2. Голубой и оранжевый цвета на кнопках отсутствуют.
3. Контраст текста (белый на тёмном) сохранён.
4. `pytest docs_project/tests/ UI/tests/` зелёный.
