# Спецификация 059 — отзывчивость UI и мелочи, которые ломают работу

## Проблема
- `UI/src/main.py:_auto_refresh_bell` создаёт новый поток на каждом тике (каждые 15 с) — потоки накапливаются, нагрузка на API лишняя (спека 055).
- `UI/src/services.py:_image_cache` ограничен только количеством записей и не очищается по времени — при долгой работе приложение держит старые миниатюры (спека 054).
- `UI/src/widgets.py` содержит два определения `_sort_by` — второе перетирает первое и теряет обработку клика по колонке «✓» (выделение всех).
- `UI/src/widgets.py:set_workers` сбрасывает выделение при каждом обновлении списка — отмеченные для экспорта анкеты теряются.
- `UI/src/api_client.py:download_file` кэширует файл в `~/.urisconsult_cache` и никогда не инвалидирует его — после перезаливки документа UI показывает старый файл.
- `UI/requirements.txt` не содержит `openpyxl`, а `pyproject.toml` — тоже: после установки по `UI/requirements.txt` экспорт в Excel падает с `ModuleNotFoundError`.
- `bot/middleware.py` считает файлы и фото в лимите 5 сообщений / 10 с — клиент, загружающий документы подряд, теряет файлы.
- Списочные запросы `db.get_all_workers` / `search_workers` / `get_workers_by_status` делают `SELECT *` вместе с тяжёлыми JSON-полями (спека 053).

## Что изменить
- Колокольчик: один долгоживущий поток с `Event.wait(15)` вместо потока на каждый тик.
- Кэш миниатюр: запись с меткой времени, старые записи (TTL 5 минут) вытесняются.
- Удалить второе определение `_sort_by`; при обновлении списка сохранять выделение для оставшихся анкет.
- После успешной перезаливки документа удалять кэшированный файл.
- `openpyxl` добавить в `UI/requirements.txt` и в `pyproject.toml`; `bot/tests` добавить в `testpaths`.
- Throttle: фото и документы не учитываются в лимите частоты.
- Списочные методы `db` — явный список колонок без `relatives_json` (нужен для списка) и без `email` (спека 014); `rejection_reasons` остаются — они нужны для экспорта карточек в PDF.

## Критерий приемки
За 15 секунд работы UI не появляется новый поток обновления колокольчика; кэш миниатюр не растёт бесконечно; клик по «✓» выделяет все строки; выделение анкет не слетает после обновления списка; после перезаливки документа открывается новый файл; экспорт в Excel работает после установки по `UI/requirements.txt`; шестой файл подряд доходит до бота.
