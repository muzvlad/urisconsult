# Спека 030 — Иконки UI: заголовок окна и EXE (все внутри одного файла)

## Проблема

1. В папке `UI/` лежат `icon.png` и `icon.ico`, но они не используются в коде и не попадают в собранный EXE.
2. EXE собирается через `--onefile` — всё должно быть упаковано в один файл, без внешних папок с ресурсами.
3. Заголовок окна — текст `"URIS Consult — Просмотр карточек"`; требуется заменить буквы `"UR"` на картинку `icon.png`, убрать слово «Consult», оставить `icon.png` + текст `"IS"`.
4. Стандартная иконка Python (перье) в заголовке окна и у самого EXE файла — заменить на `icon.ico`.
5. Размеры иконок должны подстраиваться под размеры интерфейса, не теряя квадратную пропорцию.

## Решение

### Упаковка иконок в single EXE
- `UI/build_exe.py`: добавить `icon.ico` и `icon.png` через `--add-data` в команду PyInstaller.
- PyInstaller `--onefile` упакует оба файла внутрь одного EXE; в runtime они доступны через `sys._MEIPASS`.
- Параметр `--icon=icon.ico` задаёт иконку самого EXE-файла (Windows показывает её в проводнике, в панели задач и в ярлыке по умолчанию).

### Доступ к иконкам в runtime
- `UI/src/config.py`: функция `_icon_path(name)` — возвращает `Path(sys._MEIPASS) / name` в frozen-режиме, и `Path(__file__).parent.parent / name` в dev-режиме (`UI/` рядом с `src/`).

### Заголовок окна
- `UI/src/main.py`: метод `_setup_ui()` вызывает `root.iconbitmap(icon.ico)` для иконки в titlebar.
- `_create_top_bar()` больше не показывает текст `"URIS Consult"`; вместо этого `_create_header_logo()` создаёт `tk.Frame` с `tk.Label` (иконка `icon.png` через `tk.PhotoImage`) и `tk.Label` с текстом `"IS"` + версия.
- Слово «Consult» убрано из визуального заголовка.
- `root.title()` оставлен для панели задач (taskbar) с полным названием.

### Размеры иконок (адаптивные, квадратные)
- `icon.png` в заголовке: размер вычисляется динамически — `max(16, min(64, window_height * 0.05))`, всегда квадрат (обрезка по центру + ресайз через PIL с сохранением пропорций).
- При изменении размера окна (`<Configure>`) иконка пересчитывается и пересоздаётся с новым квадратным размером.
- `icon.ico` — стандартный формат с множественными вложенными размерами (16×16, 32×32, 48×48, 256×256), Windows выбирает подходящий автоматически.

### Ярлык запуска EXE
- `UI/build_exe.bat`: после успешной сборки создаётся ярлык `[Search]Driver.lnk` в `dist/` с иконкой `icon.ico` (через PowerShell/WScript.Shell).

### Версия
- Версия приложения берётся из `CHANGELOG.md` (как в предыдущих коммитах) и показывается в заголовке: `icon.png` + `IS v1.28`.

## Файлы

- `UI/icon.png` — уже добавлена пользователем.
- `UI/icon.ico` — уже добавлена пользователем.
- `UI/src/main.py` — кастомный заголовок с адаптивным `icon.png` + текст «IS»; `root.iconbitmap(icon.ico)`.
- `UI/src/config.py` — функция `_icon_path(name)` для доступа к иконкам в frozen/dev режимах.
- `UI/build_exe.py` — `--add-data` для `icon.ico` и `icon.png`, `--icon=icon.ico`.
- `UI/build_exe.bat` — создание ярлыка с иконкой `icon.ico` после сборки.
- `docs_project/CHANGELOG.md` — запись `v1.28`.
- `docs_project/specs/archives/030-ui-icons.md` — эта спека (после завершения).

## Критерии приёмки

- EXE собирается одним файлом (`--onefile`), внутри которого лежат `icon.png` и `icon.ico`.
- При запуске EXE заголовок окна отображает `icon.png` слева и текст `IS` справа (слово «Consult» убран).
- Иконка в titlebar окна — `icon.ico` (не перо Python).
- Иконка самого EXE-файла в проводнике — `icon.ico`.
- Ярлык в `dist/` имеет иконку `icon.ico`.
- Размер `icon.png` в заголовке квадратный, подстраивается под размер окна/шрифта, пропорция не искажается.
- `python -m py_compile UI/src/main.py` и `UI/build_exe.bat` проходят без ошибок.
- Иконки не требуют внешних файлов рядом с EXE — всё внутри бандла.

## Проверка

- Запустить `UI/build_exe.bat`, проверить `dist\[Search]Driver.exe` (иконка файла), ярлык (иконка ярлыка).
- Запустить EXE, проверить заголовок окна (картинка + IS) и titlebar-иконку.
- Изменить размер окна UI — иконка в заголовке должна масштабироваться, сохраняя квадратную форму.
- Запустить в dev-режиме через `UI\run.bat`, проверить кастомный заголовок с `icon.png`.
