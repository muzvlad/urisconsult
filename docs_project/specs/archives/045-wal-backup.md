# Спецификация 002 — корректный бэкап БД в режиме WAL

## Проблема
`bot/backup_db.py:32` делает `shutil.copy2(DB_PATH, backup_path)`. БД в режиме WAL (`bot/services/db.py:_ensure_wal`), некоммиченные изменения живут в `-wal` файле. Простая копия `.db` теряет последние изменения или восстанавливает неконсистентное состояние.

## Что изменить
Использовать SQLite online backup API (`sqlite3.Connection.backup`) или копировать атомарно `.db` + `-wal` + `-shm` вместе.

## Критерий приемки
Бэкап содержит все закоммиченные на момент запуска данные; после восстановления из бэкапа `PRAGMA integrity_check` проходит, данные не потеряны.

## ponytail
Минимум кода: обертка над `sqlite3.connect(...).backup(...)`.
