# Спека 038 — Почистить репозиторий от артефактов сборки/окружения

## Проблема

В репозитории могли присутствовать `bot/venv/`, `__pycache__/`,
`.pytest_cache/`, `.coverage`, `*.pyc` и другие артефакты. `.gitignore` есть,
но артефакты уже были закоммичены.

## Решение

1. Проверен `.gitignore`: правила для `venv/`, `.venv/`, `env/`, `__pycache__/`,
   `*.py[cod]`, `.pytest_cache/`, `.coverage`, `htmlcov/`, `*.log`, `dist/`,
   `build/`, `*.spec` уже есть.
2. Индекс git проверен — артефактов в нём не осталось (110 файлов, все
   исходники). Удалять из индекса (`--cached`) было нечего.
3. В `.gitignore` добавлены каталоги `logs/` и `bot/logs/` — раньше правило
   было только на файлы `*.log`, и посторонний файл в каталоге логов попал бы
   в индекс.
4. Убраны незакоммиченные остатки иконок:
   - `UI/icon-converted.ico` — побайтовая копия `UI/icon.ico` (MD5 совпадает),
     удалён;
   - `UI/apple-touch-icon.svg` — векторный мастер иконки (1254×1254, 80 path),
     переименован в `UI/icon.svg` и добавлен в репозиторий: `icon.png`
     (500×500) и `icon.ico` — растровые производные от него.

Рабочие файлы на диске не удалялись, кроме дубликата иконки.

## Файлы

- `.gitignore` — добавлены `logs/`, `bot/logs/`.
- `UI/icon.svg` — векторный мастер иконки (вместо `apple-touch-icon.svg`).
- git index — артефактов не содержал.

## Критерии приёмки

- [x] `bot/venv/` не в индексе git.
- [x] Массовые `__pycache__` не трекаются.
- [x] `.gitignore` покрывает эти пути.
- [x] Тесты и запуск не ломаются (225 тестов проходят).
