# Спецификация 006 — пробрасывать HTTP-ошибки API в UI

## Проблема
`UI/src/api_client.py:_get/_put/_post` ловят `urllib.error.HTTPError` и возвращают `None`/`{}`. UI не отличает «404 не найдено» от «500 ошибка сервера» — показывает пустой результат или общую ошибку.

## Что изменить
Вспомогательные методы `_get/_put/_post` должны пробрасывать исключение с кодом HTTP (или возвращать структуру `{status, data, error}`), чтобы UI показывал корректные сообщения пользователю.

## Критерий приемки
При 404 API UI показывает «не найдено», при 500 — «ошибка сервера», а не пустой список.

## ponytail
Не добавлять новый клиент (httpx/requests); доработать существующий на urllib.
