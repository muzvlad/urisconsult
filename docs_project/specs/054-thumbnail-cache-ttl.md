# Спецификация 011 — ограничить кэш миниатюр DocumentService по времени/размеру

## Проблема
`UI/src/services.py:53` `_image_cache` ограничен только количеством (50 записей) и не очищается по времени. Долго работающее приложение держит в памяти миниатюры старых файлов.

## Что изменить
Добавить TTL или LRU-вытеснение по времени для `_image_cache`; очищать кэш при закрытии окна/при смене работника.

## Критерий приемки
Кэш не растёт бесконечно при длительной работе; старые записи вытесняются.

## ponytail
Простой словарь с меткой времени и очисткой старше N минут, без новых зависимостей.
