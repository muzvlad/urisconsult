# Спека 001 — Видимая диагностика отсутствующих документов в UI

## Проблема

В UI при открытии карточки сотрудника часть миниатюр документов (6 из 8 в типичном случае) **молча не показывается**. Пользователь не понимает:
- документ не загрузился по сети (таймаут, 5xx),
- файла реально нет на диске бота (рассинхрон БД ↔ файловая система),
- файл битый в локальном кэше `~/.urisconsult_cache`,
- битый doc_type в БД (неизвестный ключ).

Текущий код в `UI/src/main.py:608-619` тихо пропускает документ, если `download_file` вернул `None` или `full_path.exists() == False`. В итоге у пользователя создаётся ощущение «документов нет», хотя они числятся в БД.

Дополнительно: ошибки Telegram `Bad Gateway` в логах бота — **не связаны** с UI. Это временная недоступность `api.telegram.org` для long-polling, aiogram ретраит автоматически.

## Цель

Сделать «пропавшие» документы **видимыми** с понятной причиной, без изменения API или БД.

## Решение (минимальный диф)

В `UI/src/main.py:608-619`:
- Заменить тихое `continue`/`не показывать` на запись в `missing_docs` с указанием причины (`not_found`, `cache_invalid`, `network_error`).
- После цикла, если есть `missing_docs` — отрисовать секцию «Не загружено (N)» с перечислением `label — причина — filename`.
- Импортировать `logging` и логировать каждую причину на уровне `WARNING` с `worker_id`/`doc_type` для последующей диагностики.

Никаких новых файлов. Никаких изменений в API/БД/боте. Локальный кэш остаётся как был.

## Что НЕ делаем

- Не добавляем «Перезагрузить» / «Retry» — лишний UI, источник проблемы надо чинить на стороне бота (sync_docs_from_disk).
- Не трогаем `api_client.py` и `api_server.py` — нет доказательств, что проблема в сети.
- Не чиним Telegram `Bad Gateway` — это инфраструктурный шум.

## Проверка

1. Открыть карточку сотрудника, у которого часть документов отсутствует на диске.
2. Вместо молчаливого пропуска должна появиться секция «Не загружено (N)» со списком.
3. В `ui_error.log` — записи `WARNING ... docs missing: worker=... type=... reason=... file=...`.
4. Регрессии: документы, которые есть, продолжают показываться миниатюрами.

## Файлы

- `UI/src/main.py` — единственный изменяемый файл.
