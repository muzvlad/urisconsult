# Спецификация 010 — убрать SELECT * с тяжёлыми JSON-полями в списочных методах

## Проблема
`db.get_all_workers` / `search_workers` / `get_workers_by_status` (`bot/services/db.py:743-797`) делают `SELECT *`, включая длинные JSON-поля `relatives_json` и `rejection_reasons`. Для списка в UI они не нужны — лишний трафик и память.

## Что изменить
Добавить вариант выборки без тяжёлых полей (явный список колонок) для списочных методов; полные данные — только по `get_worker`.

## Критерий приемки
Списочные методы не возвращают `relatives_json`/`rejection_reasons`; `get_worker` возвращает полную запись.

## ponytail
Не менять `get_worker`; добавить колонки явно в списочные запросы.
