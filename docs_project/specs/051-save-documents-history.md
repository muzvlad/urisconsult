# Спецификация 008 — не стирать created_at при перезагрузке документа

## Проблема
`db.save_documents` (`bot/services/db.py:654`) делает `DELETE` по `worker_id, doc_type` и заново вставляет. При перезагрузке того же документа `created_at` обновляется — история того, когда файл загружен впервые, теряется.

## Что изменить
При перезагрузке под тем же именем не перезаписывать `created_at` первой загрузки.

## Критерий приемки
После перезагрузки документа дата первой загрузки сохраняется (не сбрасывается на время перезагрузки).

## ponytail
Не вводить отдельную таблицу истории; доработать `save_documents`/`replace_document` с условием.
