# Десктопное приложение URIS Consult

## Описание

Tkinter-приложение для поиска, просмотра и обработки карточек сотрудников.
UI не открывает SQLite напрямую: все данные и файлы он получает по HTTP от
API-сервера, который запускается вместе с Telegram-ботом.

## Запуск

```bash
cd UI
run.bat
```

`run.bat` создаёт `.venv`, устанавливает зависимости и запускает `db_viewer.py`.

Вручную:

```bash
cd UI
pip install -r requirements.txt
python db_viewer.py
```

Перед запуском UI запустите бота (`bot/bot.py`): API слушает порт `56755`.
Если сервер недоступен, запросы завершаются ошибкой после 30 секунд ожидания.

## Сборка EXE

```bash
cd UI
build_exe.bat
```

EXE: `dist/[Search]Driver.exe`. Сборка через PyInstaller (`--onefile`),
работает без установленного Python.

## Возможности

- Поиск по ФИО, телефону, должности, объекту и другим полям
- Фильтр по периоду: сегодня, неделя, месяц, прошлый месяц, год, произвольный
- Переключение «Активные / Архив / Все»
- Список с сортировкой по колонкам и локальным фильтром
- Бейджи статуса бота и цветные плашки HR-статуса
- Колокольчик новых анкет, обновление раз в 15 секунд
- Принятие и отклонение анкет с причинами
- Отправка замечаний клиенту в Telegram
- Редактирование полей карточки
- Изменение юр. лица отдельным действием
- Замена документов
- Открытие фото и документов в системном приложении
- Встречи: добавление, просмотр, уведомления клиенту
- Комментарии: добавление, изменение, удаление
- HR-статус с датой приёма или увольнения
- Архивирование и возврат из архива
- Удаление сотрудника вместе с файлами
- Экспорт карточки в PDF

## Интерфейс

### Верхняя панель

- «Все анкеты» — сброс поиска и возврат к активным
- «PDF» — экспорт текущей карточки
- «Показать» — Активные / Архив / Все
- Колокольчик — количество анкет со статусом `pending`

### Панель поиска

- Поле поиска и кнопка «Найти»
- «Период»: Все время, Сегодня, За неделю, За месяц, Прошлый месяц,
  За год, Произвольный
- Для произвольного периода — даты «с» и «по» и кнопка «Применить»
- «Сброс» — возврат к активным анкетам за всё время

### Левая панель

Список `Treeview` с колонками:

`Статус бота`, `ID`, `ФИО`, `Дата`, `Категория`, `Менеджер`, `Объект`, `HR-статус`

Строки подсвечиваются цветом HR-статуса; архивные записи отображаются серым.
Над списком есть локальный фильтр по тексту. Клик по заголовку сортирует.

### Правая панель

1. Заголовок: ФИО, статус бота, ИД, фото
2. Кнопки: Редактировать, В архив / Вернуть из архива, Удалить
3. HR-статус: выпадающий список, плашка и дата; кнопка «Сохранить»
4. Даты создания, изменения и архивации
5. Личные данные: категория, пол, дата рождения, менеджер, объект,
   заказчик, юр. лицо, адрес, должность, телефоны, семейное положение,
   родственники
6. Встречи: список и кнопка «Добавить встречу»
7. Комментарии: список с изменением и удалением
8. Документы: превью по категории, дата загрузки, замена и открытие
9. Замечания при отклонении

## Работа с API

Адрес API определяется в `src/config.py` в таком порядке:

1. Переменная окружения `API_SERVER`
2. Строка `API_SERVER=` из `bot/.env` или `.env` в корне
3. `http://144.76.70.246:56755`

Токен доступа (`API_TOKEN`) читается из тех же источников и отправляется
в заголовке `X-API-Token`. Если сервер требует токен, а UI его не знает —
ответ 401, в лог UI пишется текст ошибки.

Клиент `APIClient` использует только стандартную библиотеку (`urllib`).
Таймаут одного запроса — 30 секунд. Ошибки HTTP пробрасываются как
`APIError` с кодом: 404 на карточке — «не найдено», 500 — «ошибка сервера».

Файлы документов скачиваются через `GET /docs/<worker_id>/<filename>` и
кэшируются в `%USERPROFILE%\.urisconsult_cache\{worker_id}`. При замене
документ отправляется на `POST /api/workers/<id>/documents`, кэшированный
файл удаляется, карточка перезагружается.

## Обработка анкет

### Колокольчик

Показывает количество `pending`, обновляется каждые 15 секунд. Клик открывает
окно со списком новых анкет.

### Принятие

Меняет статус бота на `accepted`.

### Отклонение

Диалог позволяет выбрать поля и документы с замечаниями и добавить комментарий.
После сохранения бот уведомляет клиента в Telegram; клиент исправляет анкету
через `/start`, и она снова становится `pending`.

### HR-статус

| Ключ | Подпись |
|---|---|
| `not_processed` | Новый |
| `docs_pending` | Ожидает документы |
| `employed` | Трудоустроен |
| `rejected` | Отказ |
| `fired` | Уволен |

Для «Трудоустроен» и «Уволен» обязательна дата в формате `ДД.ММ.ГГГГ`.
HR-статус не меняет статус бота и хранится в `workers.hr_status`.

### Встречи

При добавлении встречи бот отправляет клиенту сообщение, а за 24 часа до
встречи — напоминание. Для архивных анкет уведомления не отправляются.

### Архив

Архивация заполняет `archived_at`, возврат очищает его. Архивные анкеты
видны при выборе «Архив» или «Все».

## Даты

В интерфейсе даты показываются как `ДД.ММ.ГГГГ`, дата и время —
`ДД.ММ.ГГГГ ЧЧ:ММ`. Ввод дат в диалогах принимается строго в формате
`ДД.ММ.ГГГГ` и преобразуется в ISO для API.

## Тесты

```bash
python -m pytest UI/tests -q
```

36 тестов: конфигурация, даты и HR-статусы, модели, сервисы, технические
сценарии UI (встречи, бейджи, обновление карточки).

## Ограничения

- Без запущенного API-сервера UI не работает с данными.
- При недоступном сервере каждый запрос ждёт до 30 секунд.
- Кэш документов не очищается автоматически.
