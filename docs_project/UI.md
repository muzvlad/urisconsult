# Десктопное приложение URIS Consult

## Описание

GUI-приложение для просмотра карточек сотрудников. Читает данные из SQLite базы бота и отображает документы.

## Запуск

```bash
cd UI
# Автоматически создаст venv и установит зависимости
run.bat
```

Или вручную:
```bash
cd UI
pip install -r requirements.txt
python db_viewer.py
```

## Сборка EXE

```bash
cd UI
build_exe.bat
```

EXE будет в `dist/[Search]Driver.exe`. Работает на любом компьютере без Python.

## Возможности

- **Поиск** — по ФИО, телефону, email, должности, объекту
- **Показать всех** — список всех сотрудников
- **Просмотр карточки** — основная информация + документы по категории
- **Колокольчик уведомлений** — новые анкеты (pending)
- **Обработка анкет** — принятие / отклонение с выбором полей
- **Отправка замечаний** клиенту в Telegram
- **Открытие документов** — клик по изображению открывает в стандартном приложении
- **Экспорт в PDF** — полная карточка с документами
- **Редактирование** — изменение полей карточки
- **Удаление** — полное удаление сотрудника (БД + файлы)

## Интерфейс

### Верхняя панель
- Поле поиска + кнопка «Найти»
- Кнопка «Показать всех»
- Кнопка «Экспорт в PDF»
- 🔔 Колокольчик уведомлений (количество pending анкет)

### Левая панель
Список найденных записей: `ID — ФИО` с иконкой статуса (⏳/✅/❌)

### Правая панель
Карточка сотрудника:

1. **Заголовок** — ФИО, ИД, фото
2. **Личные данные** — гражданство, пол, должность, объект
3. **Контакты** — телефоны, email
4. **Документы** — превью документов по категории
5. **Кнопки** — Редактировать / Удалить

## Хранение данных

Приложение использует ту же SQLite базу что и бот:

| Ресурс | Путь |
|---|---|
| БД | `bot/Users/users.db` (или сетевой `\\144.76.70.246\urisconsult\bot\Users\users.db`) |
| Документы | `bot/Users/docs/` |

### Определение путей

1. Сначала проверяется сетевой сервер `\\144.76.70.246\urisconsult`
2. Если недоступен — fallback на локальную БД
3. Пути кэшируются через `@lru_cache`

### Синхронизация файлов

При запуске приложение сканирует `bot/Users/docs/` и дописывает недостающие записи в `worker_documents`. Это обеспечивает консистентность между файловой системой и БД.

## Обработка анкет

### Колокольчик
- Показывает количество анкет со статусом `pending`
- Обновляется каждые 15 секунд
- Клик открывает окно обработки

### Окно обработки
- Список всех pending анкет
- Клик по анкете → карточка с деталями
- **Принять** → статус `accepted`
- **Отклонить** → выбор полей для исправления → отправка в Telegram

### Отклонение
- Чекбоксы с полями для исправления
- Кнопка «Отклонить и отправить»
- Бот отправляет клиенту inline-кнопки «Исправить» / «Новая анкета»

## database is locked

Если бот и UI работают с одной БД одновременно, возможна ошибка «database is locked».

**Решение:** UI использует retry logic с экспоненциальной задержкой (5 попыток, 0.5-2.5 сек). Также установлен `PRAGMA busy_timeout=5000`.
