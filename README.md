# URIS Consult

Система для работы с анкетами сотрудников: Telegram-бот собирает данные от людей, десктопное приложение помогает HR-менеджерам их обрабатывать. Всё работает через общий API — UI не лезет в базу напрямую.

## Что внутри

```
urisconsult/
├── bot/                    # Telegram-бот + API-сервер (Flask на порту 56755)
├── UI/                     # Десктопное приложение на Tkinter
├── shared/                 # Единая схема БД (SQLite) — общая для бота и UI
├── docs_project/           # Документация, спеки, чейнджлог
└── memory.md               # Важные архитектурные решения
```

## Как это работает

1. **Клиент пишет боту** — пошагово заполняет анкету (ФИО, гражданство, должность, документы и т.д.)
2. **Бот сохраняет в SQLite** и параллельно поднимает HTTP API на `0.0.0.0:56755`
3. **HR открывает десктопное приложение** — оно тянет данные через API
4. **HR видит новые анкеты** (колокольчик вверху показывает количество)
5. **Принимает или отклоняет** — при отклонении выбирает, какие поля исправить, бот шлёт замечания человеку в Telegram
6. **Человек исправляет** — анкета снова становится `pending`
7. **Доп. фишки**: встречи с уведомлениями, комментарии, HR-статусы (принят/увольнен/на проверке МВД), архив, экспорт в PDF

## Быстрый старт

### 1. Подготовка

```bash
# Клонируем
git clone <repo>
cd urisconsult
```

### 2. Настройка бота

```bash
cd bot
cp .env.example .env   # или создайте .env вручную
# В .env обязательно: BOT_TOKEN=ваш_токен_от_BotFather
# Опционально: API_TOKEN=сложная_строка (если хотите закрыть API)
```

### 3. Запуск бота (обязательно первым!)

```bash
# В папке bot
pip install -r requirements.txt
python bot.py
```

Бот поднимет API на порту 56755. В консоли будет:
```
==================================================
  URIS CONSULT BOT — РАБОТАЕТ
==================================================
  БД: bot/Users/users.db
  Документы: bot/Users/docs
  API: http://0.0.0.0:56755
==================================================
```

### 4. Запуск UI

Откройте **новый терминал**:

```bash
cd UI
run.bat
```

`run.bat` сам создаст виртуальное окружение, поставит зависимости и запустит приложение. Откроется окно со списком анкет.

> **Важно:** Бот должен быть запущен **до** UI. Без API-сервера UI не получит данные.

## Сборка EXE для HR-менеджеров

```bash
cd UI
# Если API закрыт токеном — задайте его перед сборкой:
set UI_BUILD_API_TOKEN=ваш_токен
build_exe.bat
```

Готовый `Driver.exe` (или `SearchDriver.exe`) появится в `UI/dist/`. В него зашит токен — сотрудникам настраивать ничего не нужно. Просто кидаете exe на рабочий стол.

Переопределить токен на конкретной машине можно `.env` рядом с exe или переменной окружения `API_TOKEN` — они важнее вшитого.

## Основные возможности UI

| Что делает | Как пользоваться |
|------------|------------------|
| **Поиск и фильтры** | Поиск по любому полю, период: сегодня/неделя/месяц/год/произвольный |
| **Статусы на виду** | Бейджи: статус бота (ожидает/принята/отклонена) + HR-статус |
| **Принятие / отклонение** | Кнопки в карточке. При отклонении — галочки полей + комментарии → уходят в Telegram |
| **Редактирование** | Любое поле анкеты, юр. лицо отдельной кнопкой |
| **Документы** | Открытие фото/PDF, замена файла (перетаскивать не надо — кнопка «Заменить») |
| **Встречи** | Добавление даты/времени/примечания → бот сам пришлёт уведомление и напоминание за 24ч |
| **Комментарии** | Внутренние заметки по сотруднику (не уходят клиенту) |
| **HR-статус** | not_processed → docs_pending → employed / rejected / fired + дата |
| **Архив** | Убрать из рабочего списка, вернуть обратно |
| **Экспорт** | PDF по одной карточке или Excel всего списка |
| **Колокольчик** | Обновляется каждые 15 секунд, показывает новые `pending` |

## Архитектура в двух словах

- **Единый порт** — 56755. Это HTTP API (Flask в фоновом потоке бота). У бота нет своего порта (long polling), у UI нет порта (клиент), у SQLite нет порта (файл).
- **shared/__init__.py** — **единственный источник истины** для схемы БД. И ботик, и UI, и миграции читают оттуда.
- **API — мост**. UI не имеет прямого доступа к БД. Все операции: чтение списка, карточка, документы, статусы, встречи, заметки — через HTTP.
- **Безопасность**: `worker_id` и `filename` в URL проверяются по regexp (нет path traversal), тип файла — по magic-байтам, размер запроса — 20 МБ. Авторизация опциональна: если в `.env` задан `API_TOKEN`, нужен заголовок `X-API-Token`.

## Структура БД (shared/__init__.py)

| Таблица | Назначение |
|---------|------------|
| `workers` | Анкета, статус бота, HR-статус, архив, юр. лицо, заказчик, родственники (JSON) |
| `worker_documents` | Файлы: `worker_id`, `doc_type`, `filename`, `created_at`. Несколько файлов на один тип — ок |
| `worker_meetings` | Встречи: дата, примечание, флаги уведомлений/напоминаний |
| `worker_notes` | Комментарии HR: текст, даты создания/обновления |

### Статусы

| Поле | Значения |
|------|----------|
| `status` (бот) | `pending`, `accepted`, `rejected` |
| `hr_status` (внутренний) | `not_processed`, `docs_pending`, `employed`, `rejected`, `fired` |
| Архив | `archived_at` пусто / дата архивации |

## Конфигурация (bot/.env)

```
BOT_TOKEN=              # обязательно, токен от @BotFather
NETWORK_SERVER=         # путь к сетевой шар (SMB) для БД и документов. Пусто — локально bot/Users/
API_SERVER=http://127.0.0.1:56755   # адрес API для UI (читается также из env)
API_TOKEN=              # если задан — API требует X-API-Token. Пусто — открыто
API_PORT=56755          # порт API
```

> **NETWORK_SERVER**: если шара недоступна — бот пишет предупреждение в лог и падает на локальную `bot/Users/`.

## Частые вопросы

**Q: Почему два отдельных процесса (бот + UI), а не один?**
A: Бот — долгоживущий asyncio-процесс (polling Telegram). UI — синхронный Tkinter. Разделение упрощает жизнь: бот не блокируется GUI, UI не тянет aiogram/aiohttp. Связывают HTTP API.

**Q: Можно ли запустить API отдельно от бота?**
A: Да, `python bot/api_server.py` — поднимет только Flask на том же порту. Удобно для отладки UI без бота.

**Q: Где лежат документы?**
A: `bot/Users/docs/{worker_id}/` (или на сетевой шар если задан `NETWORK_SERVER`). UI кэширует их к себе в `%USERPROFILE%\.urisconsult_cache\{worker_id}\`.

**Q: Как сменить IP сервера для UI?**
A: Переменная окружения `API_SERVER` или `API_SERVER=` в `.env` рядом с exe / в `bot/.env`. Приоритет: env var → `.env` рядом с exe → `bot/.env` → дефолт `http://144.76.70.246:56755`.

**Q: Зачем в EXE вшит токен?**
A: Чтобы HR-менеджерам не настраивать ничего. Токен в бинарнике извлекаем — секретность даёт закрытый порт 56755 (не открыт во внешнюю сеть). Переопределить можно `.env` рядом с exe.
