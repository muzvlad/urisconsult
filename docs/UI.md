# Десктопное приложение URIS Consult

## Описание

GUI-приложение для просмотра карточек сотрудников. Читает данные из SQLite базы бота и отображает документы.

## Запуск

```bash
cd UI
pip install -r requirements.txt
python db_viewer.py
```

Через скрипт: `run.bat`

## Возможности

- **Поиск** — по ФИО через SQL-запрос
- **Показать всех** — список всех сотрудников
- **Просмотр карточки** — основная информация + документы по категории
- **Открытие документов** — клик по изображению открывает в стандартном приложении
- **Экспорт в PDF** — полная карточка с документами

## Структура приложения

```
UI/
├── db_viewer.py          # Основной модуль (GUI + логика)
├── build_exe.py          # Сборка в .exe через PyInstaller
├── requirements.txt      # Зависимости
├── run.bat               # Скрипт запуска
├── build_standalone.bat  # Сборка автономного .exe
└── .venv/                # Виртуальное окружение
```

## Интерфейс

### Верхняя панель
- Поле поиска + кнопка «Найти»
- Кнопка «Показать всех»
- Кнопка «Экспорт в PDF»

### Левая панель
Список найденных записей: `ID — ФИО`

### Правая панель
Карточка сотрудника:

1. **Заголовок** — ФИО, ИД, фото
2. **Личная информация** — гражданство, пол, должность, объект, адрес, менеджер, телефоны, email, дата рождения
3. **Документы** — секции по каждой категории документа (только заполненные)
4. **Встречи** — если есть

## Документы

Документы отображаются динамически на основе поля `citizenship`.

### Патент (12)
Паспорт, СНИЛС, Регистрация, Миграционная карта, ДМС, Патент, ИНН, Чек по патенту, Сертификат о знании языка, Реквизиты банковской карты, Дактилоскопическая карта

### Студент (10)
Паспорт, СНИЛС, Регистрация, Миграционная карта, ДМС, ИНН, Дактилоскопическая карта, Справка из ВУЗа, Реквизиты банковской карты

### ЕАЭС (9)
Паспорт, Регистрация, Миграционная карта, ДМС, ИНН, СНИЛС, Дактилоскопическая карта, Реквизиты банковской карты

### РВП (7)
Паспорт, Миграционная карта, ДМС/ОМС, ИНН, СНИЛС, Реквизиты банковской карты

### ВНЖ (9)
Паспорт, Миграционная карта, ВНЖ, ДМС/ОМС, ИНН, СНИЛС, Трудовая книжка/ЭТК, Реквизиты банковской карты

### Россия (9)
Паспорт, Паспорт прописка, Прописка, ИНН, СНИЛС, Документ об образовании, Трудовая книжка/ЭТК, Военный билет/Приписное

## Хранение

| Ресурс | Путь |
|---|---|
| БД | `bot/Users/users.db` |
| Документы | `users/docs/` |

Пути фиксированные — приложение автоматически находит БД и документы относительно корня проекта.

## Сборка .exe

```bash
cd UI
python build_exe.py
```

Результат: `dist/[Search]Driver.exe`

Скрипт автоматически устанавливает PyInstaller и собирает автономный exe-файл.

## Требования

- Python 3.7+
- Pillow >= 9.0.0
- reportlab >= 3.6.0 (для PDF)
- Windows (для .exe сборки)
