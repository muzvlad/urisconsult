# Changelog

## v2.0 (12.07.2026)

Объединение бота и UI в единый проект. Переход с JSON на SQLite.

### Бот
- Переход хранения данных с JSON на SQLite (aiosqlite)
- Миграция существующих JSON-файлов в БД
- 40+ типов документов по 6 категориям гражданства
- Общая БД `bot/Users/users.db` для бота и UI

### UI (Десктопное приложение)
- Полная замена JSON-чтения на SQLite
- Динамическое отображение документов по категории гражданства
- Убран выбор папки — фиксированные пути к БД и документам
- Автоматическое создание БД и папок при первом запуске
- Экспорт PDF со всеми документами

### Структура
- Перенос .git из `bot/` в корень проекта
- Единая папка документов `users/docs/`
- Единая документация в `docs/`
- Обновлён .gitignore

## v1.0 (09.07.2026)

Telegram-бот для сбора данных работников.

### Возможности
- Пошаговая анкета через FSM: ФИО, гражданство, пол, должность, объект, адрес, менеджер
- Валидация телефона, email, даты рождения
- Загрузка документов: фото, паспорт, патент, регистрация
- Экран подтверждения с возможностью редактирования любого поля
- Сохранение в JSON + файлы документов
- Кнопка «Начать регистрацию» всегда видна
- Ответ на любое сообщение вне анкеты с предложением нажать старт

### Исправления
- Токен вынесен в .env
- Убран жесткий формат телефона
- Исправлен пропуск документов (ошибка в лямбдах)
- Кнопки клавиатуры не исчезают после нажатия
- Убран дублирующий код в обработчике документов
- Очистка служебных ключей из сохраняемого JSON
- Логирование: только ошибки бота, без шума от библиотек
