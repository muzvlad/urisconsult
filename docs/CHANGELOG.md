# Changelog

## v2.2 (13.07.2026)

Система обработки анкет: колокольчик уведомлений, принятие/отклонение, возврат на доработку.

### UI
- **Колокольчик уведомлений** — иконка 🔔 + серый кружок с количеством pending анкет
- **Панель обработки** — окно со списком новых анкет (клик по колокольчику)
- **Принятие анкеты** — кнопка "Принять" ставит статус `accepted`
- **Отклонение анкеты** — выбор полей для исправления через чекбоксы, отправка замечаний клиенту в Telegram
- **Статус в списке** — ⏳ (pending) / ✅ (accepted) / ❅ (rejected) рядом с каждой анкетой
- **Панель замечаний** — жёлтая секция в карточке с перечнем отклонённых полей
- **Центрирование окон** — все диалоги открываются по центру экрана
- Кнопки в окне отклонения: "Отмена" + "Отклонить и отправить" (внизу, всегда видны)
- Scrollbar в окне отклонения (при большом количестве полей)

### Бот
- `/start` проверяет `telegram_id` → ищет отклонённую анкету
- Если анкета отклонена: предлагает "Исправить" или "Новая анкета"
- Исправление: запрашивает только отклонённые поля
- При переподаче: статус → `pending` (снова в UI для обработки)

### БД
- Новые колонки: `status` (`pending`/`accepted`/`rejected`), `rejection_reasons` (JSON)
- Новые функции: `get_pending_workers()`, `accept_worker()`, `reject_worker()`, `resubmit_worker()`

### Тесты
- 5 тестовых анкет (Тестовый*) с разными статусами и категориями
- Скрипт `seed_test_data.py` для генерации тестовых данных

## v2.1 (12.07.2026)

Рефакторинг архитектуры: нормализованная БД, единый конфиг документов, generic handlers, тесты.

### Бот
- **config/documents.py** — единый источник истины для типов документов
- **Нормализованная БД** (3NF): `workers`, `worker_documents`, `worker_meetings`
- **Generic document handler** — 1 вместо 60+ функций-обработчиков
- **Динамический FSM** — WorkerForm генерируется из конфига
- **Rate limiting** — ThrottlingMiddleware
- **Логирование** — RotatingFileHandler, структурированные логи
- **Бэкапы** — скрипт `backup_db.py`
- **Валидация файлов** — проверка MIME-типа и размера (20MB max)
- **Исправление Россия** — убран дублирующийся документ `russia_propiska`

### UI
- Импорт общего конфига документов из `bot/config/documents.py`
- Работа с нормализованной БД

### Тесты
- 62 теста: конфиг документов, БД, хендлеры
