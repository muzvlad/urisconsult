# Telegram-бот URIS Consult

## Описание

Telegram-бот для пошагового сбора данных сотрудников. Ведёт анкету через FSM (Finite State Machine), загружает документы, сохраняет всё в SQLite.

## Запуск

```bash
cd bot
pip install -r requirements.txt
echo BOT_TOKEN=ваш_токен > .env
python bot.py
```

## Диалог с ботом

### 1. Регистрация

Бот запрашивает по порядку:

| Шаг | Поле | Тип ввода |
|---|---|---|
| 1 | ФИО | Текст |
| 2 | Гражданство | Кнопки: Патент / Студент / ЕАЭС / РВП / ВНЖ / Россия |
| 3 | Пол | Кнопки: Мужской / Женский |
| 4 | Должность | Текст |
| 5 | Объект | Текст |
| 6 | Адрес объекта | Текст |
| 7 | Менеджер | Текст |
| 8 | Основной телефон | Текст (валидация) |
| 9 | Доп. телефон | Текст (опционально) |
| 10 | Email | Текст (валидация) |
| 11 | Дата рождения | Текст ДД.ММ.ГГГГ (валидация) |

### 2. Загрузка документов

Документы зависят от категории гражданства:

**Патент (12 документов):**
Фото → Паспорт → СНИЛС → Регистрация → Миграционная карта → ДМС → Патент → ИНН → Чек → Сертификат языка → Реквизиты карты → Дактилоскопическая карта

**Студент (10 документов):**
Фото → Паспорт → СНИЛС → Регистрация → Миграционная карта → ДМС → ИНН → Дактилоскопическая карта → Справка из ВУЗа → Реквизиты карты

**ЕАЭС (9 документов):**
Фото → Паспорт → Регистрация → Миграционная карта → ДМС → ИНН → СНИЛС → Дактилоскопическая карта → Реквизиты карты

**РВП (7 документов):**
Фото → Паспорт → Миграционная карта → ДМС/ОМС → ИНН → СНИЛС → Реквизиты карты

**ВНЖ (9 документов):**
Фото → Паспорт → Миграционная карта → ВНЖ → ДМС/ОМС → ИНН → СНИЛС → Трудовая книжка → Реквизиты карты

**Россия (9 документов):**
Фото → Паспорт → Паспорт прописка → Прописка → ИНН → СНИЛС → Документ об образовании → Трудовая книжка → Военный билет

Каждый документ можно пропустить (кнопка «Пропустить»).

### 3. Подтверждение

Экран с полной сводкой данных. Кнопки:
- **Подтвердить** — сохранение в БД
- **Редактировать** — выбор поля для исправления
- **Отмена** — начало заново

## Хранение данных

### База данных

Путь: `Users/users.db` (SQLite)

Таблица `workers` — 65 колонок:

| Группа | Колонки |
|---|---|
| Основное | id, name, citizenship, gender, position, object, object_address, manager |
| Контакты | phone_main, phone_additional, email, date |
| Документы | photo, passport, patent_*, student_*, eaeas_*, rvp_*, vnzh_*, russia_* |
| Мета | registration, telegram_id, telegram_username, created_at, meetings |

### Файлы документов

Папка: `users/docs/`

Именование: `{prefix}_{worker_id}.{ext}`

Префиксы определены в `config.py` → `DOC_PREFIXES`.

## Валидация

| Поле | Правило |
|---|---|
| Телефон | Цифры, +, -, (), пробелы. Минимум 10 цифр |
| Email | Должен содержать @ и . |
| Дата рождения | Формат ДД.ММ.ГГГГ, от 1900 до текущей даты |

## Технические детали

- **FSM**: aiogram 3.0 MemoryStorage
- **БД**: aiosqlite (async)
- **Клавиатуры**: Reply (действия) + Inline (гражданство)
- **Токен**: файл `.env` → `BOT_TOKEN`
- **Логирование**: только ошибки бота
